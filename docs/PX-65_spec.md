# PX-65 仕様書

2026-10-18 作成、2026-10-23 更新

## 概要

PX-65は、65C02を搭載した架空のポケットコンピューターです。ローカル環境のブラウザで動くエミュレーターと、その上で動く自作ROM(モニターとBASIC)を作ることを目的とします。

実在の機種の再現ではないため、ROMを含むすべてをこの仕様に沿って自作します。著作権のある既存ROMは使いません。

## ハードウェア概要

| 項目 | 仕様 |
| --- | --- |
| CPU | 65C02 @ 1MHz |
| RAM | 32KB(`$0000-$7FFF`) |
| ROM | 24KB(`$A000-$FFFF`)。モニター、アセンブラ、BASIC |
| 画面 | 96×32ドットのモノクロ液晶。6×8フォントで16文字×4行 |
| キー | 8×8マトリクス、約50キー。BREAKキーはNMI |
| タイマー | 64HzのIRQ |
| サウンド | 1ビットのブザー |
| 外部記憶 | 仮想テープ(ファイルの読み込みと保存) |

## メモリマップ

アドレス空間64KBのうち、下位32KBがRAM、上位24KBがROMで、その間にI/Oを置きます。

| アドレス | サイズ | 内容 |
| --- | --- | --- |
| `$0000-$00FF` | 256B | ゼロページ |
| `$0100-$01FF` | 256B | スタック |
| `$0200-$03FF` | 512B | システムのワークエリア |
| `$0400-$057F` | 384B | VRAM |
| `$0580-$7FFF` | 約30.6KB | ユーザー用RAM(内蔵ROMのBASICは `$07FF` からを使う。`$07FF` はプログラムの直前の0、`$7FFF` は `VAL` の作業用) |
| `$8000-$80FF` | 256B | I/O |
| `$8100-$9FFF` | 約7.7KB | 未使用(拡張用に予約) |
| `$A000-$FFFF` | 24KB | ROM(末尾の`$FFFA-$FFFF`は割り込みベクタ) |

ROMの中の分け方(ROMが決めることだが、内蔵ROMは次のようにする):

| アドレス | 内容 |
| --- | --- |
| `$A000-$DFFF` | BASIC(16KB) |
| `$E000-$FFFF` | モニター、アセンブラ、BIOS(8KB)。BIOSのジャンプテーブルは`$FF00`から |

内蔵ROMのRAMの使い方は `docs/basic.md` と `docs/monitor.md` を参照。

24KBより小さいROMファイルは、末尾(`$FFFF`)にそろえて配置します。

> 2026-10-18 変更: ROMを16KB(`$C000-$FFFF`)から24KBに広げ、I/Oを`$BF00`から`$8000`に移した。I/Oの並び(下位8ビット)は変わらない。

割り込みベクタ:

- `$FFFA-$FFFB`: NMI(BREAKキー)
- `$FFFC-$FFFD`: リセット
- `$FFFE-$FFFF`: IRQ/BRK(タイマー)

## ディスプレイとVRAM

画面は96×32ドットのモノクロで、VRAMは1バイトを縦8ドットとして扱います。高さ8ドットの帯(ページ)が4本あり、各ページは96バイトです。

- アドレス = `$0400 + ページ × 96 + X座標`(ページは0〜3、X座標は0〜95)
- bit0が帯の一番上、bit7が一番下
- ビットが1なら点灯
- 6×8フォントなら、1文字の描画は6バイトの書き込みで済み、16文字×4行が表示できる

ドット(x, y)を点灯させる計算:

```
アドレス = $0400 + floor(y / 8) × 96 + x
ビット   = y mod 8
```

アナンシエーターはVRAMとは別に、`LCD_ANN`レジスタで制御します。ビットが1なら点灯します。

| ビット | 表示 | 想定する用途 |
| --- | --- | --- |
| 0 | BUSY | プログラム実行中、処理中 |
| 1 | SHIFT | SHIFTが有効 |
| 2 | CAPS | 大文字・小文字の切り替え |
| 3 | DEG | 角度の単位(度) |
| 4 | RAD | 角度の単位(ラジアン) |
| 5 | RUN | 実行モード |
| 6 | PRO | プログラムモード |
| 7 | LOW | 電池残量の低下 |

用途はROMが自由に決めてかまいません。表の用途は目安です。内蔵ROMでの使い方(BUSY はテープとモニターの G での実行中、SHIFT は SHIFT が効いているあいだ、DEG / RAD は角度の単位、RUN は BASIC のプログラムの実行中。CAPS、PRO、LOW は使わない)は `docs/basic.md` と `docs/monitor.md` を参照。

## I/Oレジスタ

I/Oはすべて`$8000-$80FF`にあります。下表にないアドレスは未定義です(読み出すと`$FF`、書き込みは無視)。

| アドレス | 名前 | 方向 | 動作 |
| --- | --- | --- | --- |
| `$8000` | KEY_ROW | 読み書き | スキャンする行を選ぶ(選んだ行のビットだけ0)。読むと最後に書いた値が返る |
| `$8001` | KEY_COL | 読み出し | 選んだ行で押されている列のビットが0 |
| `$8002` | LCD_ANN | 読み書き | アナンシエーターのビット(「ディスプレイとVRAM」を参照) |
| `$8003` | LCD_CTRL | 読み書き | bit0: 表示オン、bit4-7: コントラスト |
| `$8010` | TIMER_CTRL | 読み書き | bit0: IRQ有効。bit7: 読むと要求あり、1を書くとクリア |
| `$8020` | BEEP | 書き込み | bit0の値をそのままブザーに出力 |
| `$8030` | TAPE_DATA | 読み書き | 仮想テープの1バイト。再生中に読むと次のバイトに進む。録音中に書くと追加する |
| `$8031` | TAPE_CTRL | 読み書き | 書き込み: 再生、録音、停止。読み出し: 状態(「仮想テープ」を参照) |

## 周辺機能

### キーボード

- 8×8マトリクスに51キー
- `KEY_ROW`に行を選ぶ値(例: 行2なら`%11111011`)を書き、`KEY_COL`を読む。押されている列が0になる
- BREAKキーはマトリクスに含めず、押すとNMIが発生する
- キーが返すのは位置だけで、文字への変換(SHIFTとの組み合わせを含む)はROMが行う

マトリクスへの割り当て(空欄は未使用):

| 行 \ 列 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | A | B | C | D | E | F | G | H |
| 1 | I | J | K | L | M | N | O | P |
| 2 | Q | R | S | T | U | V | W | X |
| 3 | Y | Z | SPACE | RET | SHIFT | DEL | , | . |
| 4 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 5 | 8 | 9 | + | - | * | / | = | |
| 6 | ← | → | ↑ | ↓ | | | | |
| 7 | | | | | | | | |

本体のキーの並び:

```
 [液晶 96×32]                       BRK  DEL   ←  →  ↑  ↓
 Q  W  E  R  T  Y  U  I  O  P        7  8  9  /
 A  S  D  F  G  H  J  K  L           4  5  6  *
 Z  X  C  V  B  N  M  ,              1  2  3  -
 SHIFT     SPACE          RET        0  .  =  +
```

エミュレーターでは、PCのキーボードからも入力できます。英字、数字、記号はそのままのキー(記号は、PX-65でその記号を出すキーとSHIFTの組み合わせに変換する。キーボードの配列にはよらない)、RETはEnter、DELはBackspaceかDelete、SHIFTはShift、BREAKはEsc、矢印は矢印キーです。テンキーの数字と記号、Enter も使えます。

### タイマー割り込み

- 64Hz、つまり15,625サイクルごとにIRQの要求を立てる
- `TIMER_CTRL`のbit0が1のときだけCPUにIRQを出す
- 割り込み処理の中で、bit7に1を書いて要求をクリアする

### サウンド

- 1ビットのブザー。ROMは`BEEP`のbit0を反転させて矩形波を作る
- エミュレーターは反転したサイクル位置を記録し、Web Audioで音を生成する

### 仮想テープ

- 実機のカセットの代わりに、バイト列をそのままファイルとして読み書きする
- ファイル名の指定はエミュレーターのUIで行う
- テープは1本だけ入る。最大65,536バイト
- 読み書きに待ち時間はない(書いたらすぐ記録され、読めばすぐ次のバイトが来る)

`TAPE_CTRL`に書く値:

| 値 | コマンド | 動作 |
| --- | --- | --- |
| `$00` | STOP | 止める。録音中だったら、それまでに書いたバイト列がテープの中身になる |
| `$01` | PLAY | 先頭に戻して再生を始める |
| `$02` | RECORD | テープの中身を消し、先頭から録音を始める |
| `$03` | APPEND | テープの中身を残したまま、最後に続けて録音を始める |
| `$04` | CANCEL | 録音をやめ、録音を始める前の中身に戻す(録音した分は捨てる) |

`TAPE_CTRL`を読んだときのビット:

| ビット | 名前 | 意味 |
| --- | --- | --- |
| 0 | PLAY | 再生中 |
| 1 | REC | 録音中 |
| 5 | FULL | 録音中で、テープがいっぱい(65,536バイト)になったために書けなかったバイトがある。次に `TAPE_CTRL` に書くと消える |
| 6 | EOT | 再生中で、もう読むデータがない |
| 7 | READY | 再生中で、`TAPE_DATA`から次のバイトを読める |

- 再生中に`TAPE_DATA`を読むと次のバイトが返り、読む位置が1つ進む。データがないとき、再生中でないときは`$FF`
- 録音中に`TAPE_DATA`に書くと、そのバイトを末尾に足す。録音中でなければ無視する。テープがいっぱいなら足さずに FULL を立てる。ROMは書き終えたら FULL を調べ、立っていれば CANCEL で録音前の中身に戻す
- リセットするとテープは止まる(録音中の内容は残る)。テープの中身はリセットでも電源を切っても消えない
- デバッガのメモリ表示は`TAPE_DATA`を読んでもテープを進めない

テープに書くデータの形式はROMが決める。内蔵ROM(モニターとBASIC共通)の形式は `docs/basic.md` と `docs/monitor.md` を参照。

> 2026-10-19 変更: `APPEND`(`$03`)を足した。ステートの保存形式にテープを含めた(版2。以前の保存は読み込めない)。
>
> 2026-10-22 変更: `CANCEL`(`$04`)と、状態のビット5 `FULL` を足した(いっぱいのテープに保存すると、途中で切れたブロックが残っていたため)。

## リセット、未定義領域、タイミング

**電源を入れたとき、リセットしたとき**

- `$FFFC-$FFFD`のベクタから実行を始める
- I/Oレジスタはすべて0(IRQ無効、表示オフ)から始まる。テープは止まる
- 電源を入れたときは、RAMを0で埋める。電源を切っても内容を残す設定をエミュレーター側に用意する(「電源を切ってもRAMを残す」。初めて開いたときはオン)。残したときは、ROMから見るとリセットと同じ(内蔵ROMはウォームスタートし、BASIC はプログラムを残して変数を消す)
- リセットでは、RAMはそのまま残る

**未定義の領域**

- `$8100-$9FFF`と、未定義のI/Oアドレスは、読み出すと`$FF`を返し、書き込みは無視する
- ROM領域への書き込みは無視する

**タイミング**

| 項目 | 値 |
| --- | --- |
| CPUクロック | 1,000,000 Hz |
| 描画 | 60fps |
| 1フレームのサイクル数 | 16,667 |
| タイマーの周期 | 15,625サイクル(64Hz) |

エミュレーターは`requestAnimationFrame`のたびに、前回から経過した実時間(×速度の倍率)に見合うフレーム数を実行し、その後でVRAMを画面に描画します。画面の書き換えが60Hzでない端末でも、速さは変わりません。タブを裏に回したときなどに0.1秒より長く空いた分は、まとめて実行せずに捨てます。音は、速度が×1のときだけ鳴らします。

## エミュレーターの機能と今後

### エミュレーター側の機能

- 電源、リセット、BREAKキー
- 実行速度の倍率(×1、×2、×4、×10)。音のオンとオフ
- ステートの保存と復元(1つ)、電源を切ってもRAMを残す設定(初めはオン。どちらもブラウザの localStorage に保存)、RAMを消去して起動し直すボタン(コールドスタート)
- デバッガ(レジスタ、逆アセンブル、メモリ表示、一時停止、1命令ずつ・1フレームずつの実行、ブレークポイント)
- ROMファイルの読み込み(次に開いたときも使う)と、内蔵ROMに戻す
- 仮想テープのファイルの読み込み、ファイルへの保存、取り出し(テープの中身は次に開いたときも残る)
- 画面のキーとPCのキーボードでの入力。キーを押す・離すは、ROMが読み落とさない間隔(押したキーは2回読まれるまで離さない、離したキーは1回読まれるまで押さない)でマトリクスに反映する(`web/keyqueue.js`)
- 画面の SHIFT キーの効き方の切り替え(次の1文字だけ効く / 押している間だけ効く)
- スマートフォン(縦持ち、横持ち)。振動に対応した端末では、キーを押すと振動する(切り替えられる)
- 日本語版と英語版(`dist/px65.html`、`dist/px65-en.html`)
